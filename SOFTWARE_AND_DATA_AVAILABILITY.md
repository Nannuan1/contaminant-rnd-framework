# Software and data availability

- **Software:** Gaussian-calibrated numerical-diffusion risk framework
- **Developers:** Kaijie Zhang, Dong Xu, Saiyu Yuan, Qihua Ran, Huiming Zhang,
  and Hongwu Tang
- **Contact:** Dong Xu, xudong@hhu.edu.cn
- **Languages:** Python
- **Software required:** Python 3.11 or later
- **Dependencies:** NumPy, pandas, SciPy, Matplotlib, and Plotly
- **Source code:** this repository (`scripts/`)
- **Documentation:** `README.md` and `docs/method_and_files.md`
- **Test data:** `examples/`
- **Compact reference results:** `reference/`
- **Calibration data:** compact examples are included; complete calibration summaries are not included here
- **Code licence:** MIT
- **Example-data licence:** CC BY 4.0

The manuscript should provide the repository URL and, if the complete
calibration summaries are deposited separately, the corresponding archive link.
