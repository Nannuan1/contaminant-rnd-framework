# Calibration smoke subset

This directory contains 16 archived calibration records for each of the eight
schemes. The subset uses a time-step factor of 0.3, `tau = 30`, and `Pe = 10`
or `25` across the eight calibrated `Nw` levels.

The subset is supplied to test the analysis workflow and input schema. It is
not statistically sufficient to reconstruct the final 95% envelopes, which
were fitted using all 5,376 calibration records.
