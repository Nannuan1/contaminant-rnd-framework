# Non-Gaussian V9 cosine-bell example

Parameters:

```text
profile = cosine bell
Nw = 1.25
Pe = 8.0
time-step factor = 0.4
tau = 75
prior atlas choice = van Leer
```

The `vanleer/` and `mc/` folders contain numerical profiles and the same
convolution reference solution. The prior choice was made from the frozen
Gaussian atlas before these profiles were evaluated. Van Leer ranked second in
the post-simulation score and MC ranked first for this example.
